02 · Problema

Canvas puede ser poderoso, pero no siempre es intuitivo.

Los usuarios no expertos deben navegar menús, cursos, tareas y calificaciones. Canvitas reduce esa fricción permitiendo pedir acciones con frases naturales.

⌕

Antes

El usuario busca manualmente dentro de Canvas: curso → calificaciones → actividad → detalle.

Ruta mental:
“¿Dónde estaban mis calificaciones? ¿Era en tareas o en módulos?”
✦

Con Canvitas

El usuario escribe lo que necesita y el sistema interpreta intención, entidades y acción.

Consulta:
“Muéstrame mis calificaciones”
03 · Solución propuesta

Un sistema híbrido: MiniLM entiende, ToD decide.

Canvitas no depende de un LLM pesado. Usa un modelo MiniLM para NLU y un gestor de diálogo orientado a tareas para ejecutar, confirmar o preguntar cuando hay ambigüedad.

04 · Marco teórico

Conceptos clave para entender Canvitas.

Esta sección explica de forma sencilla las tecnologías y conceptos que hacen posible que Canvitas entienda lenguaje natural y lo convierta en acciones dentro de Canvas LMS.

Modelo

MiniLM

MiniLM es un modelo de inteligencia artificial ligero basado en Transformers. Sirve para entender texto, pero consume menos recursos que modelos más grandes. En Canvitas se usa para interpretar lo que el usuario escribe.

Diálogo

ToD

ToD significa Task-oriented Dialogue, o diálogo orientado a tareas. Es un sistema que no solo conversa, sino que busca completar una acción concreta, como consultar tareas, calificaciones o cursos.

Lenguaje

NLU

NLU significa Natural Language Understanding. Es la parte de la IA que permite comprender qué quiere decir una persona cuando escribe una frase normal, aunque no use comandos exactos.

Etiquetado

IOB

IOB es una forma de marcar palabras dentro de una frase. Indica si una palabra está al inicio de una entidad, dentro de una entidad o fuera de cualquier entidad. Es útil para detectar datos como curso, tarea o fecha.

Entrenamiento

AdamW

AdamW es un algoritmo que ayuda a entrenar modelos de IA. Ajusta los parámetros del modelo poco a poco para que aprenda mejor, evitando que memorice demasiado los datos de entrenamiento.

Entidades

NER

NER significa Named Entity Recognition. Es la tarea de encontrar información importante dentro de una frase, como nombres de cursos, fechas, tareas, usuarios o identificadores.

Framework

PyTorch

PyTorch es una herramienta para construir y entrenar modelos de inteligencia artificial. En este proyecto se utiliza durante la etapa de entrenamiento y evaluación del modelo.

Despliegue

ONNX

ONNX es un formato que permite exportar modelos de IA para usarlos en otros entornos. Ayuda a que el modelo entrenado pueda ejecutarse de forma más eficiente fuera de PyTorch.

Chatbots

RASA

RASA es una plataforma para crear asistentes conversacionales. Permite manejar intenciones, entidades y flujos de conversación. Se menciona como comparación porque Canvitas resuelve parte de esto con un modelo propio.

APIs

NL2API

NL2API significa convertir lenguaje natural en llamadas a una API. En otras palabras, transforma una frase como “muéstrame mis tareas” en una acción estructurada que un sistema puede ejecutar.

En conjunto

Canvitas combina NLU, NER, MiniLM y un enfoque ToD para entender frases escritas en español. Después, organiza esa información para preparar acciones compatibles con Canvas LMS.

07 · Generador V2

Las frases no se generan al azar.

El sistema combina plantillas gramaticales con léxico filtrado por intención, valida coherencia semántica y reintenta si la frase no cumple reglas.

Ejemplo de construcción

Plantilla: VERBO + OBJETO + del + CURSO

Léxico: consultar + calificaciones + curso IA

Resultado: “Quiero consultar las calificaciones del curso IA, por favor”

Entrenamiento

Aprendizaje multitarea.

Se entrenó con AdamW, batch size 64, 12 épocas y pérdida ponderada para priorizar entidades.

L = 0.5 · Lintent+ 1.5 · Lentity

La ponderación se ajustó porque las intenciones saturaban rápido, mientras que NER necesitaba más peso para mejorar.

10 · Comparación

¿Qué hace diferente a Canvitas?

Frente a enfoques basados en LLMs o pipelines más complejos, Canvitas prioriza ligereza, control explícito de ambigüedad y despliegue sencillo.

SistemaEnfoqueDiferencia de Canvitas
NL2APIUsa LLMs para generar llamadas o JSON de API.Canvitas usa MiniLM: menor costo, menor latencia y mayor control.
AilaAsistente generativo integrado con Canvas.Canvitas no genera contenido: traduce intenciones a acciones concretas.
RASA + CanvasPipeline conversacional con slot filling.Canvitas usa un solo modelo multitarea para intención y entidades.
11 · Limitaciones

Qué falta mejorar.

Aunque los resultados son altos, el sistema aún depende de datos sintéticos y requiere un diálogo multi-turno completo para conservar contexto.

Ejemplo: si el usuario dice “Revísalo”, Canvitas necesita contexto previo para saber a qué se refiere.
1

Dataset más natural

Reescritura con modelos más avanzados y datos reales.

2

DST completo

Seguimiento de estado para diálogos multi-turno.

3

Pruebas con usuarios

Recolectar lenguaje auténtico y hacer fine-tuning.

4

Despliegue en C++

Usar ONNX Runtime y posible cuantización INT8.
